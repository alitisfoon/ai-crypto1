# داشبورد تحلیل هوشمند TON/USDT — نسخه ۲

## نکته مهم
این نسخه به مدل هوش مصنوعی از طریق OpenAI Responses API وصل می‌شود. برای کارکرد تحلیل AI باید یک API key معتبر و دسترسی/اعتبار API داشته باشید. اشتراک ChatGPT به‌تنهایی به معنی اعتبار API نیست.

## نصب در ویندوز
1. Node.js نسخه LTS را از https://nodejs.org نصب کنید.
2. این پوشه را در کامپیوتر از حالت ZIP خارج کنید.
3. در همان پوشه، روی نوار آدرس File Explorer کلیک کنید، `cmd` بنویسید و Enter بزنید.
4. این دستور را اجرا کنید:
   `npm install`
5. فایل `.env.example` را کپی کنید و نام نسخه کپی‌شده را دقیقاً `.env` بگذارید.
6. فایل `.env` را با Notepad باز کنید و به جای متن نمونه، کلید API خود را قرار دهید:
   `OPENAI_API_KEY=کلید_واقعی_شما`
   در صورت نیاز مدل را هم در `OPENAI_MODEL` تغییر دهید.
7. اجرا:
   `npm start`
8. در مرورگر باز کنید:
   `http://localhost:3000`

## امنیت
- کلید API را داخل `public/script.js`، HTML، GitHub Pages یا پیام چت قرار ندهید.
- فایل `.env` را در GitHub بارگذاری نکنید؛ `.gitignore` آن را مستثنا می‌کند.
- این پروژه به کیف پول وصل نمی‌شود و معامله انجام نمی‌دهد.
- درخواست تحلیل با محدودیت نرخ پایه محافظت شده است؛ برای انتشار عمومی، احراز هویت، محدودیت مصرف و کنترل هزینه اضافه کنید.

## انتشار آنلاین
GitHub Pages فقط فایل‌های ایستا را میزبانی می‌کند و اجرای `server.js` را انجام نمی‌دهد. برای نسخه آنلاین باید کل پروژه (شامل سرور Node) روی یک میزبان پشتیبان Node.js مستقر شود و `OPENAI_API_KEY` را در بخش Environment Variables همان میزبان وارد کنید. پوشه `public` فایل‌های سایت است.

## محدودیت تحلیل
مدل هوش مصنوعی داده‌های قیمت/کندل و شاخص‌های محاسبه‌شده را تفسیر می‌کند؛ پیش‌بینی قطعی قیمت نیست. سیگنال‌ها ممکن است اشتباه باشند و نباید مبنای تنها تصمیم مالی قرار گیرند.


## استقرار در Render (خلاصه)
- در Render گزینه New > Web Service را انتخاب و مخزن GitHub پروژه را متصل کنید.
- Runtime: Node؛ Build Command: `npm install`؛ Start Command: `npm start`.
- در بخش Environment این متغیرها را اضافه کنید: `OPENAI_API_KEY` (کلید واقعی محرمانه) و `OPENAI_MODEL` با مقدار `gpt-6-luna`.
- سپس Deploy را بزنید. برای آزمایش می‌توانید Free را انتخاب کنید؛ سرویس رایگان پس از ۱۵ دقیقه بی‌درخواستی متوقف می‌شود و شروع مجدد ممکن است حدود یک دقیقه طول بکشد.
